# Школьное расписание

Автоматизированная система составления и ведения учебного расписания для общеобразовательных учреждений.

---

## Технологии

| Компонент | Версия |
|-----------|--------|
| Язык | C# / .NET Framework 4.7.2 |
| UI | Windows Forms |
| СУБД | SQLite (встраиваемая, сервер не нужен) |
| SQLite-драйвер | Microsoft.Data.Sqlite 10.0 + SourceGear.sqlite3 3.50 |
| Excel | ClosedXML 0.105.0 (импорт и экспорт) |
| IDE | Visual Studio 2022 |

---

## Требования

- Windows 10 / 11 (64-bit)
- .NET Framework 4.7.2 (встроен в Windows 10 и 11)
- Visual Studio 2022 (для разработки и сборки)

**SQL Server не требуется** — база данных SQLite создаётся автоматически в виде файла `SchoolTimetable.db` рядом с `.exe` при первом запуске.

---

## Быстрый старт

1. Открыть `SchoolTimeTableApp.sln` в Visual Studio
2. **Build → Build Solution** (восстановит NuGet-пакеты автоматически)
3. Запустить **F5**

При первом запуске приложение само создаёт базу данных из встроенных SQL-скриптов (`schema_sqlite.sql` и `data_sqlite.sql`). Никаких ручных действий с БД не нужно.

## База данных: SchoolTimetable.db (SQLite)

### Таблицы

| Таблица | Назначение |
|---------|-----------|
| `ParallelClass` | Параллели классов (1–11) |
| `LetterClass` | Буквы классов (А, Б, В, …) |
| `Classes` | Классы школы (параллель + буква) |
| `Teachers` | Учителя: фамилия, имя, отчество, ставка |
| `Subjects` | Названия предметов |
| `Difficulty` | Числовые значения сложности |
| `SubjectByParallel` | Предмет для конкретной параллели с уровнем сложности |
| `Workload` | Нагрузка: учитель + класс + предмет + часов/нед + подгруппа |
| `Classrooms` | Кабинеты: номер, вместимость, тип |
| `ClassroomTypes` | Типы кабинетов |
| `DayOfWeek` | Справочник дней недели |
| `LessonNumber` | Справочник номеров уроков |
| `Schedule` | Расписание: нагрузка + кабинет + день + урок + чётность недели |
| `Roles` | Роли пользователей |
| `Users` | Учётные записи пользователей |

### Представления (VIEW)

| Представление | Назначение |
|--------------|-----------|
| `vw_Schedule` | Полное расписание с пометками чётности и подгруппы |
| `vw_Workload` | Нагрузка со счётчиком поставленных уроков |
| `vw_Conflicts` | Все конфликты расписания |

### Бизнес-логика (StoredProcedures.cs)

SQLite не поддерживает хранимые процедуры — вместо них в `StoredProcedures.cs` реализованы C#-методы с транзакциями:

| Метод | Назначение |
|-------|-----------|
| `sp_AddLesson` | Добавление урока с проверкой занятости учителя |
| `sp_UpdateLesson` | Обновление урока |
| `sp_DeleteLesson` | Удаление урока |
| `sp_AddWorkload` | Добавление нагрузки с проверкой дублей |
| `sp_DeleteWorkload` | Атомарное удаление нагрузки + уроков |
| `sp_AddTeacher` | Добавление учителя |
| `sp_AddClassroom` | Добавление кабинета с проверкой номера |
| `sp_GetClassConflicts` | Получение конфликтов класса |

## Функциональность

### Вкладка «Расписание»

- Два режима: сводная таблица всех классов или вид одного класса
- Уроки чётных/нечётных недель отображаются **цветными блоками** внутри ячейки (голубой — нечётная, лиловый — чётная)
- При нескольких уроках в одной ячейке — визуальное разделение на блоки
- Фильтры: класс, учитель, день недели, ступень обучения (Начальная / Основная / Средняя)
- Поиск с жёлтой подсветкой совпадений
- Конфликты выделяются красным
- Экспорт в `.xlsx` — отдельный лист на каждый класс

### Вкладка «Составление»

- Сетка: строки = уроки 1–8, столбцы = Пн–Пт
- Клик по ячейке → диалог добавления / редактирования урока
- Занятые учителя и кабинеты помечаются ⛔ и уходят в конец списков
- Правая панель: данные выбранного урока + список конфликтов
- Ячейки с несколькими уроками (чётная/нечётная неделя) отображаются цветными блоками
- Проверка лимита уроков в день (настраивается в Настройках)

### Вкладка «Нагрузка»

**Быстрый ввод одной записи:**
- Выбор класса → список предметов **автоматически фильтруется** по параллели
- Выбор предмета → учитель **автоматически подставляется** из существующих нагрузок
- **Enter** в поле «Часов/нед» добавляет запись без мыши
- После добавления класс, учитель, часы и подгруппа остаются — только меняй предмет
- Двойной клик по строке таблицы → форма заполняется данными строки

**Массовое заполнение (BulkWorkloadForm):**
- Шаг 1: выбрать параллель → предметы фильтруются, классы параллели отмечаются автоматически
- Шаг 2: учитель, часы, подгруппа
- Шаг 3: уточнить список классов, нажать «Добавить»

**Импорт из Excel (ImportWorkloadForm):**
- Кнопка «Скачать шаблон» — создаёт `.xlsx` с заголовками, примерами и листом «Инструкция»
- Кнопка «Открыть .xlsx» — читает файл и показывает **предпросмотр**:
  - 🟢 зелёный — строка готова к импорту
  - 🟡 жёлтый — запись уже существует (будет пропущена)
  - 🔴 красный — ошибка с точным описанием (класс не найден / предмет не в «Предметы/Парал.» / учитель не найден / …)
- Импортируются только зелёные строки

Формат Excel-файла:

| Класс | Предмет | Сложность | Учитель | Часов/нед | Подгруппа |
|-------|---------|-----------|---------|-----------|-----------|
| 5А | Математика | 2 | Иванов И.И. | 3 | |
| 10А | Информатика | 3 | Сидоров К.М. | 2 | 1 |

- Учитель: полное ФИО («Иванов Иван Иванович») или сокращённое («Иванов И.И.»)
- Подгруппа: 1, 2 или пусто (весь класс)

### Вкладка «Справочники»

| Вкладка | Содержимое |
|---------|-----------|
| Учителя | ФИО, ставка; изменение по двойному клику |
| Предметы | Название; изменение по двойному клику |
| Предметы / Парал. | Привязка предмета к параллели с уровнем сложности — **необходимо заполнить перед вводом нагрузки** |
| Кабинеты | Номер, вместимость, тип |
| Классы | Параллель + буква; добавление новых букв |

Во всех полях ввода работает **Enter** для быстрого добавления.

### Настройки (⚙)

- Лимит уроков в день для каждого класса (1–4 кл. = 5, 5 кл. = 6, 6–11 кл. = 7 по умолчанию)
- Хранятся в `app.config`

### Управление пользователями (только Директор)

- Просмотр всех пользователей с ролями
- Смена пароля (с кнопкой «Показать»)
- Назначение новой роли

## Рекомендуемый порядок первоначального заполнения

1. **Справочники → Учителя** — добавить всех учителей
2. **Справочники → Предметы** — добавить все предметы
3. **Справочники → Классы** — добавить параллели и буквы классов
4. **Справочники → Предметы / Парал.** — связать каждый предмет с параллелью и сложностью *(без этого нагрузку не добавить)*
5. **Справочники → Кабинеты** — добавить кабинеты
6. **Нагрузка** — заполнить (вручную, массово или импортом из Excel)
7. **Составление** — расставить уроки по сетке расписания

## Известные ограничения

- Пароли хранятся в открытом виде — при переводе в продакшн необходимо перейти на хэширование
- Вторая смена не поддерживается в UI — уроки нумеруются 1–8
