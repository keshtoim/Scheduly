# Школьное расписание

Автоматизированная система составления и ведения учебного расписания для общеобразовательных учреждений.

---

## Технологии

| Компонент | Версия |
|-----------|--------|
| Язык | C# |
| Платформа | .NET Framework 4.7.2 |
| UI | Windows Forms |
| СУБД | Microsoft SQL Server LocalDB |
| Excel-экспорт | ClosedXML 0.105.0 |
| IDE | Visual Studio 2022 |

## Быстрый старт

### 1. Создание базы данных

Выполнить скрипты в SSMS в следующем порядке:

```
1. create_new_db.sql       — создание БД SchoolTimetable2 и заполнение справочников
2. triggers_procedures.sql — представления, триггеры, хранимые процедуры
3. fix_views.sql            — пересоздание VIEW с корректным CONVERT
4. create_users.sql         — таблицы ролей и пользователей
```

### 2. Запуск приложения

Открыть `SchoolTimeTableApp.sln` в Visual Studio → **Build** → **Run (F5)**.

## Роли пользователей

### Администратор
- Полный доступ ко всем вкладкам и функциям
- Составление и редактирование расписания
- Управление нагрузкой и справочниками
- Настройка лимитов уроков
- **Не может** менять пароли других пользователей

### Директор
- Только просмотр расписания
- **Может** менять пароли пользователей и назначать роли
- Кнопка «👤 Пользователи» в шапке

### Заместитель директора
- Полный доступ как у Администратора
- Составление расписания, нагрузка, справочники, настройки

### Учитель
- Только просмотр расписания

## Функциональность приложения

### Вкладка «Расписание»
- Сводная таблица всех классов или вид одного класса
- Фильтры: класс, учитель, день недели, **ступень обучения** (Начальная / Основная / Средняя школа)
- Поиск с жёлтой подсветкой совпадений (Enter или кнопка «Найти»)
- Экспорт в `.xlsx` с отдельным листом на каждый класс
- Конфликты выделяются красным

### Вкладка «Составление»
- Сетка расписания: строки = уроки 1–8, столбцы = Пн–Пт
- Клик по ячейке → диалог редактирования урока
- Занятые учителя и кабинеты помечаются ⛔ и идут в конец списка
- Правая панель: информация о выбранном уроке + список конфликтов
- Проверка лимита уроков в день (настраивается в Настройках)
- Быстрое добавление учителя/кабинета кнопками «+»

### Вкладка «Нагрузка»
- Таблица нагрузки со счётчиком поставленных уроков
- Добавление и удаление нагрузки (удаление атомарно убирает и уроки)
- Поиск с подсветкой строк

### Вкладка «Справочники»
- Учителя, Предметы, Кабинеты, Классы
- Добавление новых букв классов (А, Б, В, Г...)

### Настройки (⚙)
- Лимит уроков в день для каждого класса
- Хранятся в `app.config`, не требуют изменений БД
- Значения по умолчанию: 1–4 кл. = 5, 5 кл. = 6, 6–11 кл. = 7

### Управление пользователями (только Директор)
- Просмотр всех пользователей с ролями
- Смена пароля с отображением текущего (кнопка «Показать»)
- Назначение новой роли

Строка подключения находится в `DbHelper.cs`:

```csharp
public const string ConnStr =
    "Server=(localdb)\\MSSQLLocalDB;Database=SchoolTimetable2;" +
    "Trusted_Connection=True;TrustServerCertificate=true";
```

## Известные ограничения

- Пароли хранятся в открытом виде — при переходе в продакшн необходимо перейти на хэширование
- Расписание в БД заполнено только на понедельник (требуется заполнение на всю неделю)
- Вторая смена не поддерживается на уровне UI — уроки хранятся с номерами 1–8
