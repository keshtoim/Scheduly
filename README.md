# 🏫 Школьное расписание

Приложение для составления, просмотра и управления школьным расписанием.
Разработано на **Windows Forms (.NET Framework 4.7.2)** с использованием **C#** и локальной базы данных **SQL Server (LocalDB)**.

---

## 📋 Возможности

- 👁 **Просмотр расписания** — сводная таблица всех классов с фильтрами по классу, учителю и дню недели. Конфликты подсвечиваются красным
- 🗓 **Составление расписания** — сетка Пн–Пт × Уроки 1–8, назначение уроков кликом, легенда, панель конфликтов и инфо о выбранном уроке
- 📋 **Нагрузка** — управление нагрузкой учителей: кто, что и у какого класса ведёт
- 📚 **Справочники** — редактирование учителей, предметов, кабинетов и классов
- ⬇ **Экспорт в Excel** — красиво оформленный `.xlsx` файл с отдельным листом на каждый класс
- 🔐 **Авторизация** — разграничение доступа по ролям

## 🗄 База данных

Приложение работает с локальной базой **SQL Server LocalDB**.

**Строка подключения** задаётся в одном месте — файл `DbHelper.cs`:
```csharp
public const string ConnStr =
    "Server=(localdb)\\MSSQLLocalDB;Database=SchoolTimetable0;Trusted_Connection=True;...";
```

### Таблицы

| Таблица | Назначение |
|---------|------------|
| `Classes` | Классы школы (5А, 10Б и т.д.) |
| `ClassParallel` | Параллели (5, 6 ... 11) |
| `LetterOfTheClass` | Буквы классов (А, Б, В ...) |
| `Teachers` | Учителя |
| `Subjects` | Предметы |
| `Classrooms` | Кабинеты |
| `ClassroomTypes` | Типы кабинетов |
| `Workload` | Нагрузка: класс + предмет + учитель + часов/нед |
| `Schedule` | Расписание: нагрузка + день + урок + кабинет |

SQL-скрипты для создания и заполнения БД находятся в папке `sql/`.

## 🚀 Запуск

### Готовый exe
1. Скачай архив из раздела [Releases](../../releases)
2. Распакуй все файлы в одну папку
3. Запусти `SchoolTimeTableApp.exe`

### Из исходников
1. Клонируй репозиторий
2. Открой `SchoolTimeTableApp.sln` в Visual Studio 2019 или новее
3. Создай базу данных с помощью скриптов из папки `sql/`
4. При необходимости измени строку подключения в `DbHelper.cs`
5. **Build → Rebuild Solution**
6. Запусти проект (F5)
